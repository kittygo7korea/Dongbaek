# 알림 신청 → 구글 스프레드시트 연결하기

웹사이트에서 **알림받기**(헤더 창, 알림 섹션)를 제출하면 아래처럼 구글 시트에 한 줄씩 쌓입니다.

| 신청 시각 | 신청 위치 | 언어 | 이메일 | 닉네임 | 콜라보 굿즈 소식 | 동백마을체험 소식 | 관심 굿즈 | 개인정보 동의 |
|---|---|---|---|---|---|---|---|---|
| 2026-11-06 15:40 | 헤더 알림받기 창 | ko | you@example.com | 블룸이친구 | O | O |  | 동의 |
| 2026-11-06 15:42 | 알림 섹션 | ko | me@example.com |  | O |  | 블룸 컵 | 동의 |

흐름: 방문자 브라우저 → 이 사이트 서버(`/api/notify`) → 구글 Apps Script 웹 앱 → 시트
(시트 주소와 비밀값은 서버에만 있어 방문자에게 보이지 않습니다.)

---

## 1. 시트와 Apps Script 만들기 (5분)

1. [Google 스프레드시트](https://sheets.new)에서 새 시트를 만들고 이름을 정합니다. 예: `동백마을 알림 신청`
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 모두 지우고 [`notify-sheet.gs`](notify-sheet.gs) 내용을 그대로 붙여 넣습니다.
4. 맨 위 `SECRET` 값을 **아무도 모르는 긴 문자열**로 바꿉니다. (예: 비밀번호 생성기로 만든 32자 이상)
5. 저장(💾) → 위쪽 함수 선택에서 **`setup`** 을 고르고 **실행** → 권한 승인 창에서 내 계정으로 **허용**.
   시트에 `알림신청` 탭과 제목 줄이 생기면 성공입니다.

## 2. 웹 앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**
2. 유형 선택(⚙️) → **웹 앱**
3. 설정
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

> 코드를 고친 뒤에는 **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포**를 해야 반영됩니다. (URL은 그대로)

## 3. Vercel에 환경 변수 넣기

Vercel → 프로젝트(Dongbaek) → **Settings → Environment Variables**에 두 개를 추가합니다. (Production·Preview 모두 체크)

| 이름 | 값 |
|---|---|
| `GOOGLE_SHEET_WEBHOOK_URL` | 2단계에서 복사한 웹 앱 URL |
| `GOOGLE_SHEET_WEBHOOK_SECRET` | 1단계에서 정한 `SECRET`과 똑같은 값 |

저장한 뒤 **Deployments → 최신 배포 ⋯ → Redeploy** 를 한 번 눌러야 적용됩니다.

## 4. 확인

배포된 사이트에서 알림받기를 제출 → 시트에 새 줄이 생기면 끝입니다.

- 환경 변수가 없거나 시트 연결이 실패하면, 방문자에게는 “지금은 신청을 받을 수 없어요. 잠시 후 다시 시도해 주세요.”가 보이고 저장되지 않습니다.
  Vercel **Logs**에서 `[notify]`로 시작하는 오류를 확인하세요.
- 내 컴퓨터에서 시험할 때는 프로젝트 폴더에 `.env.local` 파일을 만들고 같은 두 줄을 넣습니다. (`.env*`는 깃허브에 올라가지 않음)

## 개인정보 메모

- 받는 항목: 이메일, 닉네임(헤더 창), 받을 소식, 관심 굿즈, 동의 여부, 신청 시각·위치·언어. 그 밖의 기기 정보는 저장하지 않습니다.
- 시트 공유 범위를 담당자로만 제한하고, 캠페인이 끝나면 동의 문구대로 시트를 삭제하세요.
- 스팸 방지: 사람에게 보이지 않는 칸을 봇이 채우면 저장하지 않습니다. `=`, `+`, `-`, `@`로 시작하는 값은 수식으로 실행되지 않게 앞에 `'`를 붙여 저장합니다.
